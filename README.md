# Simuladores — Uniones químicas

Colección de 7 simuladores interactivos para la unidad de uniones químicas (nivel secundario / introductorio).

Sitio de origen: https://quimica-uniones-e8r.pages.dev/simuladores

## Simuladores

| Código | Tema | Carpeta |
|--------|------|---------|
| C04 | Energía de enlace | `simuladores/sim-c04-energia-enlace/` |
| C05 | Red iónica | `simuladores/sim-c05-red-ionica/` |
| C06 | Estructuras de Lewis | `simuladores/sim-c06-lewis/` |
| C07 | Polaridad | `simuladores/sim-c07-polaridad/` |
| C08 | Mar de electrones | `simuladores/sim-c08-mar-electrones/` |
| C09 | Geometría molecular (TREPEV) | `simuladores/sim-c09-geometria-trepev/` |
| C10 | Punto de ebullición | `simuladores/sim-c10-ebullicion/` |

## Cómo verlos

Abrí `index.html` en el navegador, o serví la carpeta con cualquier servidor estático:

```bash
npx serve .
```

Cada simulador es un HTML autocontenido (CSS y JS incluidos).
